# Antes de publicar uma página

Este repositório é para quem edita. O arquivo HTML daqui foi feito para abrir no seu computador, gravar a tela e levar ao editor. Enquanto ele fica na sua máquina, o caminho é o de [`motion-html/README.md`](motion-html/README.md).

Outro cuidado começa se esse HTML, ou outro arquivo feito com IA, for para a internet: uma página de exemplos, um link público, um formulário. Aí o material certo é o primeiro produto público no GitHub do Camilo Coutinho, escrito para quem programa e publica com IA:

[Checklist de segurança para quem programa com IA](https://github.com/camilocoutinho/checklist-seguranca-vibecoding)

Este arquivo não substitui aquele checklist e não deixa um site seguro sozinho.

Três cuidados que já valem na edição, antes mesmo de publicar qualquer página:

1. Use só vídeo, áudio e marca que você tem direito de usar.
2. Não cole senha, chave de acesso nem dado de cliente dentro do prompt.
3. Assista o rascunho inteiro antes de postar. A skill de efeitos e o HTML entregam um ponto de partida. Quem aprova é você.
