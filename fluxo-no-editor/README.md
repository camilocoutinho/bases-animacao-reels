# Do arquivo até o editor

O Claude entrega um rascunho. Quem publica é o editor que você já usa. Esta pasta descreve esse trecho, em três guias:

- [CapCut](capcut.md), o destino natural do MP4 de efeito, porque a skill não coloca som nem legenda
- [Premiere Pro](premiere.md)
- [DaVinci Resolve](davinci.md)

## Dois tipos de arquivo

| O que você tem na mão | De onde veio | O que costuma faltar |
|---|---|---|
| Um MP4 com `_effects` no nome | Skill de vídeo falado | Música, efeito sonoro e legenda. A voz original continua no arquivo. |
| Uma gravação de tela | HTML de `motion-html/exemplos/` | Pode entrar muda, e às vezes com barra preta em volta do quadro vertical. |

Os dois viram clipe na linha do tempo. Nenhum dos dois é um template do programa.

## Ordem que evita retrabalho

1. Assista o rascunho fora do editor. Confira rosto livre, frase certa e tempo.
2. Importe.
3. Encaixe o quadro em 9:16. Corte a barra preta da gravação de tela, se houver.
4. Coloque música por baixo da voz. Se o clipe do HTML entrou mudo e precisa de narração, a narração entra aqui.
5. Faça a legenda e leia em voz alta. Corrija o que a legenda automática errou.
6. Exporte em vertical. Antes de apertar, confira se a largura é 1080 e a altura é 1920, e se o programa não inverteu para 1920 por 1080.

O nome do botão muda de uma versão para outra. Os guias usam o nome estável do comando e avisam quando a posição muda.
