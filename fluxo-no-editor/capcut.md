# CapCut

Use este guia quando o motion já é um vídeo: o MP4 com `_effects` no nome, ou a gravação de tela de um HTML. A skill de efeitos deixa a voz como estava e não adiciona música nem legenda. O CapCut é o lugar dessa etapa.

Os nomes abaixo aparecem no CapCut para computador e, parecidos, no aplicativo do celular. A posição muda conforme a versão. Se um botão não estiver onde o texto diz, procure pelo nome.

## 1. Criar o projeto vertical

1. Abra o CapCut e crie um projeto novo.
2. Escolha a proporção **9:16**, se essa escolha aparecer na criação. No computador ela também fica nas configurações do projeto e na hora de exportar.

## 2. Importar

1. Importe o MP4.
2. Arraste o clipe para a linha do tempo.
3. Assista uma vez antes de empilhar efeito em cima. O arquivo da skill já é o efeito.

Se o material for a gravação do HTML:

- Ela pode entrar sem áudio. Isso é o esperado: o HTML deste repositório não embute narração.
- Se aparecer barra preta, use o corte (crop) até o quadro vertical encostar nas bordas.

## 3. Música e voz

1. Importe a música numa faixa de áudio, separada da voz.
2. Baixe o volume da música até a fala continuar na frente.
3. No MP4 da skill, não substitua a faixa da voz. Ela é o áudio original.

## 4. Legenda

1. Procure **Legendas automáticas** ou **Auto captions**, no menu de texto.
2. Gere a legenda.
3. Leia tudo. Corrija nome, número e palavra que o reconhecimento errou.
4. Afaste a legenda do topo e da base. Essas faixas somem atrás dos botões do Reels.

Se preferir legendar na mão, o critério é o mesmo: a frase precisa bater com a boca, e o texto precisa caber no miolo do quadro.

## 5. Exportar

1. Abra a exportação.
2. Formato MP4.
3. Resolução 1080p, com o quadro vertical. Confira a proporção 9:16 antes de confirmar.
4. Assista o arquivo exportado, não só a prévia da linha do tempo.

O rascunho da skill é um ponto de partida. O README dela diz para assistir antes de postar. Vale aqui também.
